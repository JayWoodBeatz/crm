# Flora CRM

Главная страница CRM для учёта продаж растений. React + Vite.

## Запуск

```sh
npm ci --cache /tmp/npm-cache
npm run dev
```

Сборка: `npm run build`. Предпросмотр сборки: `npm run preview`.

Стартовые данные демонстрационные. Новые приходы и расходы сохраняются в localStorage текущего браузера и добавляются к демонстрационным показателям. График и сравнения с предыдущим периодом демонстрационные. Серверная база данных и авторизация пока не подключены.
